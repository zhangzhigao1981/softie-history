# 软乎乎 · 历史足迹

基于 [成语泡泡](https://github.com/yuanyang749/softie-idioms-app) 改造的初中历史研习小游戏。软乎乎角色、泡泡运输、连击特效、奖杯馆、签到日历等原版演出完整保留，按**统编版 2025 版**教材组织成「册 → 单元 → 课」三级目录。纯静态前端，零 npm 依赖，无构建步骤、无后端。

## 快速运行

需要 Node.js 20+ 和 Python 3。进入项目目录：

```bash
npm run dev
```

打开 `http://127.0.0.1:8016`。不要直接用 `file://` 打开 `index.html`，浏览器要通过 HTTP 加载 ES modules。验证用 `npm test`。静态文件可直接部署到 GitHub Pages 等静态托管，不需要服务端。

## 四种题型

每课每题型各 5 题，一课 20 题，全书 **26 课 520 题**（选择 / 判断 / 填空 / 材料各 130 道）。作答**全部是点选**，不用键盘输入。

| 题型 | 玩法 | 一轮 | 每题时限 |
|---|---|---|---|
| 选择题 | 四选一 | 5 题 | 40 秒 |
| 判断题 | 点「对」或「错」 | 5 题 | 35 秒 |
| 填空题 | 题干里留一个空，从候选词里挑一个补进去 | 5 题 | 45 秒 |
| 材料题 | 先读一段史料，再回答小问 | 5 题 | 70 秒 |

每题都带解析与「教材定位」（单元 · 课）。答错可继续重试；错过或跳过的题进入待复习，独立答对后移出。演示不写入练习统计。

## 命题约定

- 全部按统编版教材**原创命题**，答案与解析一并落库，不用教辅原题。
- 知识点覆盖每课正文、地图与「相关史事」「材料研读」等栏目，同一课 5 道同型题不重复考同一句话。
- 主观表述一律拆成候选词选择：材料的每个小问、填空的每个空都是「点一个」。
- 判断题的选项固定为「对 / 错」，题干只考一个可判断的事实或结论。

命题工具箱在 `js/content/kit.js`（`choice` / `judge` / `blank` / `material` 四个构造函数），各单元题库在 `js/content/<册>/`（`b7a` 七上、`b7b` 七下、`b8a` 八上、`b8b` 八下），由 `js/content/history.js` 汇总并注入 `id`、`bookId`、`unitId`、`lessonId`、`lessonLabel` 等元信息——题库文件里不写这些字段。

### 给空册补题

骨架文件里每课只有 `label` 和 `title`，加题目就是在课对象上补四个数组：

```js
import { choice, judge, blank, material } from '../kit.js';

export default {
  id: 'u1',
  no: 1,
  name: '史前时期：原始社会与中华文明的起源',
  lessons: [
    {
      label: '第1课',
      title: '远古时期的人类活动',
      choice: [choice('题干', ['A', 'B', 'C', 'D'], 0, '解析'), /* ……共 5 题 */],
      judge: [judge('这句话对不对。', 0, '解析'), /* ……共 5 题 */],
      blank: [blank('题干里留一个 ____ 。', ['词1', '词2', '词3', '词4'], 0, '解析'), /* ……共 5 题 */],
      material: [material('史料原文', '小问题干', ['A', 'B', 'C', 'D'], 0, '解析'), /* ……共 5 题 */],
    },
  ],
};
```

加完把 `tests/content.test.mjs` 里的 `PENDING_BOOK_IDS` 与对应快照更新掉，`npm test` 会顺手校验题量、题号唯一、答案落在候选项内、判断题选项固定为「对 / 错」等。整套目录结构不需要动。

## 浏览器朗读

使用浏览器 Web Speech API，无付费 API。默认自动朗读材料与题干，填空题的空位念作「空格」。题目、每个候选、解析各有独立朗读按钮；点候选的「听一听」不会提交答案。等待或朗读时暂停思考倒计时。缺声音或播放失败会给出提示，仍可继续答题。

## 原版保留与记录

`style.css`、`show.css`、`js/audio.js`、`js/bg.js`、`js/core.js`、`js/fx.js`、`js/choreography.js`、`js/softie.js`、`icon.svg`、`LICENSE-SOFTIE` 原样保留；`setShowLevel`、`cutin`、`celebrate`、`parade`、`drawStamp`、`unitSlam`、`playFinale`、`initLogoBurst` 八个舞台函数保持原文，`tests/preservation.test.mjs` 用参考提交的 SHA-256 基线（按 LF 归一化）校验。

中文题型适配全部写在独立的 `english.css`（覆盖层），不改原版样式表。签到、日历、补签金锤、每日委托、奖杯系统沿用原系统，仅替换文案与奖杯条件描述。因为一轮只有 5 题，连击奖杯门槛由英语版的 5/7/8 调整为 **3/4/5**，否则后两档永远拿不到。

学习记录存在 `softie-history:v1`，课程选择与题型存在 `softie-history:ui`。重置只删除 `softie-history:` 与旧版 `softie-english:` 数据，不影响成语版或其他应用。
