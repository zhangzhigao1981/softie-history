# 软乎乎 · 历史足迹

基于 [成语泡泡](https://github.com/yuanyang749/softie-idioms-app) 改造的初中历史研习小游戏。软乎乎角色、泡泡运输、连击特效、奖杯馆、签到日历等原版演出完整保留，按**统编版 2025 版**教材组织成「册 → 单元 → 课」三级目录。纯静态前端，零 npm 依赖，无构建步骤、无后端。

**在线地址**：<https://zhangzhigao1981.github.io/softie-history/> （GitHub Pages，`main` 分支根目录发布，push 后自动重建）

## 快速运行

需要 Node.js 20+ 和 Python 3。进入项目目录：

```bash
npm run dev
```

打开 `http://127.0.0.1:8016`。不要直接用 `file://` 打开 `index.html`，浏览器要通过 HTTP 加载 ES modules。验证用 `npm test`。静态文件可直接部署到 GitHub Pages 等静态托管，不需要服务端。

| 题型 | 玩法 | 一轮 | 每题时限 |
|---|---|---|---|
| 选择题 | 四选一 | 5 题 | 40 秒 |
| 填空题 | 题干里留一个空，从候选词里挑一个补进去 | 5 题 | 45 秒 |
| 材料题 | 先读一段史料，再回答小问 | 5 题 | 70 秒 |
| 时间轴题 | 看一条排好年份的时间轴，把空着的那个节点补上 | 5 题 | 50 秒 |

**时间轴题**考的是「时序定位」：轴上给 3～6 个年份，事件名留一处空白（显示问号），学生从候选事件里挑出该位置应当发生的那一件。素材取自教材正文的时序与每个单元开篇的单元时间轴。第 1 课已铺满 5 道（禁烟线、战争进程、开战年份、条约链、单元总轴各一道）。

每题都带解析与「教材定位」（单元 · 课）。答错可继续重试；错过或跳过的题进入待复习，独立答对后移出。演示不写入练习统计。

## 命题约定

- 全部按统编版教材**原创命题**，答案与解析一并落库，不用教辅原题。
- 知识点覆盖每课正文、地图与「相关史事」「材料研读」等栏目，同一课同型题不重复考同一句话。
- 主观表述一律拆成候选词选择：材料的每个小问、填空的每个空都是「点一个」。
命题工具箱在 `js/content/kit.js`（`choice` / `blank` / `material` / `timeline` 四个构造函数），各单元题库在 `js/content/<册>/`（`b7a` 七上、`b7b` 七下、`b8a` 八上、`b8b` 八下），由 `js/content/history.js` 汇总并注入 `id`、`bookId`、`unitId`、`lessonId`、`lessonLabel` 等元信息——题库文件里不写这些字段。

### 给空册补题

骨架文件里每课只有 `label` 和 `title`，加题目就是在课对象上补四个数组：

```js
import { choice, judge, blank, material } from '../kit.js';

export default {
  id: 'u1',
  no: 1,
  name: '史前时期：原始社会与中华文明的起源',
  lessons: [
    {
      label: '第1课',
      title: '远古时期的人类活动',
      choice: [choice('题干', ['A', 'B', 'C', 'D'], 0, '解析'), /* ……共 5 题 */],
      judge: [judge('这句话对不对。', 0, '解析'), /* ……共 5 题 */],
      blank: [blank('题干里留一个 ____ 。', ['词1', '词2', '词3', '词4'], 0, '解析'), /* ……共 5 题 */],
      material: [material('史料原文', '小问题干', ['A', 'B', 'C', 'D'], 0, '解析'), /* ……共 5 题 */],
    },
  ],
};
```

加完把 `tests/content.test.mjs` 里的 `PENDING_BOOK_IDS` 与对应快照更新掉，`npm test` 会顺手校验题量、题号唯一、答案落在候选项内、填空题恰好一个空、时间轴节点数与空位唯一等。整套目录结构不需要动。

录完一批题后先跑验收脚本，它专挑测试查不出的内容问题：

```bash
npm run audit          # 审计四册
npm run audit b8a      # 只审八年级上册
```

会拦住同课题干完全重复、同题候选项重复、填空格数不对、解析缺失；同时提示解析过短（< 12 字）、题干过长（> 60 字）、选项过长（> 24 字）这些手机上影响可读性的问题。硬问题存在时退出码为 1，能直接挂进流水线。

## 浏览器朗读

使用浏览器 Web Speech API，无付费 API。默认自动朗读材料与题干，填空题的空位念作「空格」。题目、每个候选、解析各有独立朗读按钮；点候选的「听一听」不会提交答案。等待或朗读时暂停思考倒计时。缺声音或播放失败会给出提示，仍可继续答题。
